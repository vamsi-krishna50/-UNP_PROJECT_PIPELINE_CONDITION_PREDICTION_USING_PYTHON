# UNP_PROJECT_PIPELINE_CONDITION_PREDICTION_USING_PYTHON
I did this project in collaboration with UNP, this classification project focuses on predicting pipeline conditions by analyzing different pipeline characteristics and identifying whether a pipeline is Critical or Non-Critical. The project uses data analysis and machine learning classification techniques to develop predictive models for pipeline condition assessment.

The project includes data quality checking, data preprocessing, exploratory data analysis, feature preparation, train-test splitting, model development, and model evaluation. Multiple classification models including Logistic Regression, Decision Tree Classifier, and Random Forest Classifier were implemented and compared using accuracy, precision, recall, F1-score, and confusion matrix.

The analysis provides insights into the factors influencing pipeline condition and helps identify pipelines that may require greater attention. Thickness Loss was identified as the dominant predictive feature, and the Decision Tree Classifier achieved the best performance among the tested models. The project also provides recommendations for monitoring pipeline integrity and using machine learning as a decision-support and early-warning tool.
